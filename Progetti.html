Pagina di presentazione

Tecnologie: HTML5, CSS3, Git, GitHub Pages.

Pagina web di presentazione personale concepita come curriculum vitae digitale. Suddivide i contenuti in sezioni ben definite: anagrafica, passioni personali, tabella cronologica delle esperienze scolastiche e professionali e collegamenti diretti ai canali di contatto.

Cosa ho imparato: applicare la semantica HTML per strutturare un testo biografico ed esperienziale chiaro e leggibile, stilizzare tabelle dati con proprietà di spaziatura e allineamento verticali, e definire una palette di colori coerente tra titoli, intestazioni e sfondi.

Registrazione Music Streaming

Tecnologie: HTML5, CSS3, Git, GitHub Pages.

Una pagina di registrazione completa per un servizio di streaming musicale. Il progetto include la raccolta delle informazioni personali dell'utente con input strutturati (testo, email, password, data di nascita, telefono), una griglia interattiva di card per la selezione multipla dei generi musicali preferiti e la gestione del consenso a termini e condizioni.

Cosa ho imparato: padroneggiare la logica e la semantica dei form in HTML, gestire la corretta validazione dei tipi di dati di input e progettare un'esperienza utente lineare per l'onboarding e la raccolta dati.

Teatri italiani

Tecnologie: HTML5, CSS3, Google Fonts, Git, GitHub Pages.

Sito web statico multi-pagina dedicato ai più celebri Teatri Italiani. Ciascuna scheda approfondisce la sede, la regione e l'architetto progettista con link a Wikipedia, affiancati da cover fotografiche hero a piena larghezza e un sistema circolare di navigazione interna verso i luoghi correlati.

Cosa ho imparato: strutturare e mantenere consistente un layout attraverso pagine multiple, curare la gerarchia visiva ed editoriale, collegare le risorse tramite ipertesto e rifinire la stilizzazione dei collegamenti ipertestuali e delle liste non ordinate.

YouTube clone

Tecnologie: HTML5, CSS3, Ionicons, Git, GitHub Pages.

Replica dell'interfaccia desktop di YouTube, completa di sidebar laterale di navigazione, topbar fissa con barra di ricerca, icone interattive e griglia responsive per i video feed. Ciascuna video card riproduce fedelmente thumbnail, avatar del canale, titolo del video, metadati e statistiche di visualizzazione.

Cosa ho imparato: gestire architetture CSS avanzate per layout a griglia e a colonne, importare e utilizzare librerie di icone web esterne e replicare gerarchie visive e spaziature tipiche di una web application moderna e scalabile.

Portfolio personale

Tecnologie: HTML5, CSS3, Google Fonts, Font Awesome, Git, GitHub Pages.

La pagina che state vedendo. Costruita da zero in cinque giorni, partendo dal markup HTML e arrivando alla stilizzazione CSS completa con box moled, pseudo-classi, pseudo-elementi, tipografia ragionata. Pubblicata online su GitHub Pages al termine della prima settimana di corso.

Cosa ho imparato: progettare una pagina pensando alla gerarchia dei contenuti prima del design. Stilizzare in modo consapevole partendo da un reset CSS. Gestire un repository Git con commit descrittivi. Pubblicare su un sito statico online.
